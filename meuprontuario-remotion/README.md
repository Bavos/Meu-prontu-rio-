# Meu Prontuário — Vídeo Comercial Remotion

Vídeo comercial vertical silencioso de 30 segundos para o produto Meu Prontuário.

## Rodar localmente

```bash
npm install
npm run dev
```

## Renderizar localmente

```bash
npm run artifact
```

## Arquivos gerados

```text
out/MeuProntuario_Comercial_30s_Silent.mp4
out/MeuProntuario_Thumbnail.png
out/MeuProntuario_Remotion.zip
```

## Download pelo GitHub

1. Acesse a aba Actions
2. Rode o workflow Render Remotion Video
3. Ao finalizar, abra a execução
4. Baixe o artifact MeuProntuario-Video-Final

## Especificações técnicas

- Formato vertical mobile: 1080x1920
- Duração: 30 segundos
- FPS: 30
- Total: 900 frames
- Áudio: nenhum componente ou asset de áudio é usado
- Composition ID: `MeuProntuarioComercial`
