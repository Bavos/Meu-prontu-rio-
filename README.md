# Meu Prontuário — Vídeo Comercial

Projeto em React, TypeScript e Remotion para gerar um vídeo comercial vertical, premium e silencioso do produto **Meu Prontuário**.

- Formato: 1080x1920
- Duração: 30 segundos
- FPS: 30
- Composition: `MeuProntuarioComercial`
- Sem áudio, narração, música ou efeitos sonoros

## Rodar localmente

```bash
npm install
npm run dev
```

## Renderizar vídeo

```bash
npm run artifact
```

Os arquivos serão gerados em `out/`:

- `MeuProntuario_Comercial_30s_Silent.mp4`
- `MeuProntuario_Thumbnail.png`

## Gerar vídeo pelo GitHub

1. Vá em Actions
2. Execute:
   Render Meu Prontuario Video
3. Aguarde finalizar
4. Baixe o artifact:
   MeuProntuario_FINAL
5. Extraia o ZIP
6. Assista:
   MeuProntuario_Comercial_30s_Silent.mp4
